# MemberKey

Plugin WordPress gratuit: abonamente, restricție de conținut și Download-uri protejate. Spec-ul e în `docs/SPEC.md`.

## Agent skills

### Issue tracker

Tichetele stau ca fișiere markdown în `.scratch/<feature>/issues/`. See `docs/agents/issue-tracker.md`.

### Triage labels

Cele cinci roluri canonice, cu etichetele implicite (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`). See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: `GLOSSARY.md` + `docs/adr/` în rădăcină. See `docs/agents/domain.md`.
